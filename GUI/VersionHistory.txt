TTHighSpeedDownloader GUI 版本历史
====================================

v0.4.0 [新功能/优化]
    新增功能：
    - 添加 Logger 日志系统
    - 增加 tip 弹窗组件

    架构优化：
    - 将使用到的外部库完全从网络获取释放到本地
    - 拆分 GUI 的 HTML 使其更好维护

    UI 改进：
    - 修改一些样式
    - 更新 README 文档

v0.3.0 [新功能/改进]
    新增功能：
    - 增加浏览路径功能
    - 可以阅读 MD 文件以及普通文件
    - 增加浏览器 UA 的修改功能

    下载功能：
    - 现在可以根据 URL 自动获取文件名
    - 如果没有文件名，将会使用 download_file 为文件名

    UI 改进：
    - 修改下载任务列表 UI
    - 修改进度条显示
    - 修改 UI（简单的优化）
    - 修改字体
    - 修改图标

    文档：
    - 增加 README
    - 更新 README

v0.2.0 [新功能/重构]
    新增功能：
    - 增加配置文件支持

    UI 改进：
    - 删除标题栏的退出和最小化按钮
    - 使用系统提供的窗口管理器

v0.1.0 [初始发布]
    - 初始版本发布

---
说明：
- [新功能]：添加了新特性
- [修复]：修复了 bug
- [优化]：性能或代码优化
- [改进]：功能或 UI 改进
- [重构]：代码结构调整，不改变功能

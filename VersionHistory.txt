TTHighSpeedDownloader 版本历史
=================================

v0.5.1 IV1 [修复/优化]
    内部架构改进：
    - 下载器现在统一使用 context 控制取消
    - 移除了 HSDownloader.Downloader 字段
    - 使用 sync.WaitGroup 跟踪活动任务
    - 导出函数中正确处理了删除

    优化：
    - 重构了 TTHSD_interface.py 使其的代码更好维护

    兼容性说明：
    - 暂停功能限制：暂停后无法恢复下载
    - 错误事件格式：某些错误之前以 EventTypeMsg 形式发送，现以修复
    - 停止行为：不等待任务退出，立即清理资源

v0.5.0 [新功能/重构]
    内部架构升级：
    - 内部更好扩展
    - 现在如果下载没有可用进程，将会发送结束消息
    - 现在下载器如果发现拥有空闲线程，将自动分配新任务

    API 修改：
    - 增加 UA 标识（用户可以通过 API 传参修改）
    - 修改回调更新消息的下载量为绝对下载量
    - 修改消息发送机制为异步
    - 增加 err 事件
    - 修改下载器 API（具体修改请查看 API 说明）

    新增支持：
    - 增加 BT、ED2K、FTP 下载支持（未进行大规模测试，官方 编译 中未支持 ）

    性能优化：
    - 增加高性能下载器实现（已合并到普通下载器）
    - 更新下载器性能
    - 使下载能正常暂停或停止

v0.4.0 [新功能]
    API 修改：
    - 增加 UA 标识（用户可以通过 API 传参修改）
    - 修改回调更新消息的下载量为绝对下载量
    - 修改消息发送机制为异步
    - 具体修改请查看：[API 说明](./docs/API%20Description.md)

v0.3.0 [重构]
    - 删除不使用的方法（API 修改）
    - 增加任务 ID（API 修改）

v0.2.0 [破坏性变更]
    - 修改传参，现在是 json 格式的传参（API 修改）

v0.1.0 [初始发布]
    - 初始版本发布

---
说明：
- [新功能]：添加了新特性
- [修复]：修复了 bug
- [优化]：性能或代码优化
- [重构]：代码结构调整，不改变功能
- [破坏性变更]：不兼容的 API 变更
